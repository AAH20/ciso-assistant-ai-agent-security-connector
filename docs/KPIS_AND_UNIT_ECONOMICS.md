# KPI and unit-economic mappings

The connector transports measurements; it does not invent them. Numerators,
denominators, time windows, environments and classifications belong in the
source evidence.

## Recommended metric families

### Agent security

- Critical Attack Success Rate
- Unauthorized Action Prevention Rate
- Approval Bypass Rate
- Cross-Tenant Leakage Rate
- Agent-Induced Incident Rate

### Reliability

- Recovery Success Rate
- Successful Reversal Rate
- Mean Time to Safe State
- Fail-Closed Test Pass Rate

### Evidence and GRC

- Evidence Completeness
- Evidence Freshness
- Decision Reproducibility
- Control Traceability
- Stale Evidence Exposure Hours

### Utility

- Secure Utility
- Benign Task Success Rate
- False Denial Rate
- Citation Accuracy
- Unsupported Claim Rate

### Economics

- Cost per Safe Successful Task
- Cost per Accepted Evidence Object
- Cost per Safe Validated Resolution
- Net Toil Value Saved
- Break-Even Safe-Task Volume
- Gross Margin per 1,000 Safe Tasks

Pipeline is not revenue. Expected-loss reduction must come from a calibrated,
probabilistic risk scenario rather than alert severity or failed controls.
